# 文献笔记：DynaSchedBench: Calibrated Dynamic Scheduling Benchmarks and Observability Paradox in LLM-based Scheduling Agents
- **来源**：ICML 2026（Proceedings of the 43rd ICML, Seoul, PMLR 306），北航（计算机学院/深圳LoopArea研究院等）+ 西电，Shijie Cao, Yuan Yuan（通讯）, Jing Liu 等；arXiv 2605.27566；项目主页 https://dsbx7.github.io/
- **研究问题**：
  动态柔性作业车间调度（DFJSP）的评测存在一个方法论张力（methodological tension）：一边是静态基准（Taillard 1993、DMU/Demirkol et al. 1998），静态、有限、确定性，训练/评测于固定实例集导致基准过拟合（agent 记忆特定实例结构而非学习可泛化策略），且完全无法捕捉真实生产系统（Industry 4.0）的连续随机事件流——频繁作业到达、机器故障、加工时间波动；另一边是未校准（uncalibrated）的过程式实例生成器，"难度"只是随机种子的不受控副产品，给评测引入高方差"随机雾"（stochastic fog）：无法区分算法表观增益是真实创新还是恰好碰到有利的动态事件序列。论文要回答：如何把实例难度和分布变成受控变量，从而可靠评测 LLM 调度智能体的推理能力？在此基础上系统诊断 LLM 智能体在步进式在线决策中的失效方式。

- **基准构成**：
  - **问题定义与实例生成**：输入配置四元组 I = (P, θ_distri, m*, θ_dyn)：植物结构 P=(M,G,F,w)（机器集 M 及速度 v_m、机器分组 G、工艺模板库 F 与各模板工序序列 K_f 及名义加工均值 µ_{f,o}、作业混合概率 w）；随机分布参数 θ_distri（到达间隔 ~ Gamma(k_a,θ_a)、加工时间 ~ Gamma、批大小 ~ N(µ_B,σ_B²)、预防维护时长 ~ 正态）；目标度量向量 m* = (ρ*_global, c2*_a, c2*_p, τ*, χ*_load, δ*, {ρ*_b})（全局利用率、到达/加工 SCV、交期紧度、负载不均衡、扰动比、瓶颈窗口利用率）；动态场景 θ_dyn = (p_cancel, p_rework, p_prio, p_route, p_ddchg, ∆_pm, ...) 控制作业取消、返工、优先级变化、路径变化、交期更新、预防性维护等事件频率。生成器把配置变成完全实现的离散事件流 E：基础到达率 λ_base 由目标利用率反解（式2）；平稳更新到达（式5 Gamma 参数由目标 SCV 反解）；非平稳到达用时间扭曲（time-warping，式6-8：λ(t)=λ_base·g(t)，g 支持常数/周期/线性包络，单调变换 T_k=Λ^{-1}(T^raw) 保持到达顺序）；基础交期 D_j^(0)=t_j+τ*·W_j；扰动按容量损失预算 δ*·C_tot 用故障/维修/维护事件实现（式10-12）。
  - **规模**：DynaSched-Grid = 六个主驱动度量的全因子网格（ρ*_global∈{0.50…0.95}、τ*∈{2…10}、c2*_a∈{0.25…4.0}、c2*_p∈{0.25…2.0}、δ*∈{0…0.15}、χ*_load∈{0,0.15,0.30}），每配置 5 个独立种子；基础车间 10 机器/4 机组/3 作业族/平均路径长 4 工序。DynaSched-Sweep = 以质心配置（ρ*=0.85,τ*=5.0,c2_a*=1.0,c2_p*=0.5,δ*=0.05,χ*=0.1）做细粒度单/双参数扫描的局部敏感性库。扩展规模实验 N_J∈{200,400,800,1600}（H≈1107.5–8859.7）。LLM 评测用 DynaSched-Subset：70 实例（30 Grid + 40 Sweep），对 6 维驱动度量 + 难度百分位排名做 Z-score 后用最远点贪心 k-center 采样，KS 统计量（难度 0.175 / 利用率 0.086 / 到达 SCV 0.251）验证对全池覆盖、保留全 IQR。
  - **难度校准机制（两层）**：(1) SESC（Sequential Event-Space Calibrator）做"生成后校准"：不经参数重采样，直接在已实例化的事件列表 E 上做局部结构变换（算子目录 S：到达结构调整=rate correction 删除/复制作业 + renewal resampling 保序重生成时间戳；自适应交期松弛缩放 D'_j=t_j+clip(α·ξ_j)（式33-34）；同构加工时间重采样 p'=p̃·Σp/Σp̃（式35，严格守恒总负载同时命中目标 SCV）；瓶颈工程调停机事件时长或插入补偿维修事件（式36））。每轮按影响向量 a_s 与非对称惩罚 φ 算 Score(s)=Σφ(a_{s,ℓ},e_ℓ)（式31-32），贪心选最降低归一化误差向量 e（式29）且不伤害已收敛度量的算子。对比基线：参数空间多目标优化 MOO（NSGA-II，12D/5D 决策向量）与 Hybrid。表1：SESC 中位 L2 误差 0.0539 / 中位耗时 0.2s / 种子间 Std 0.0236，均显著优于 MOO（0.0826 / 57.9s / 0.1532）与 Hybrid（0.0595 / 185.8s / 0.0562）；relaxed 成功率 SESC 84% vs Hybrid 78% vs MOO 57%，strict 48%/49%/29%。(2) SSI（Schedule Stress Index）做"难度量化"：见指标节。**难度由此成为受控变量的机制是**：SESC 先把实例"钉"在目标度量点（消除随机种子漂移），SSI 再把已实现事件流映射为标量难度分并分位数分层，两者合起来把"难度"从随机种子副产品变成生成协议中的显式设定值。

- **指标定义**（逐条，编号为原式号）：
  - 生成层：λ_base = ρ*_global·Σv_m/MeanP（2）；MeanP = Σ_f w_f Σ_o µ_{f,o}（3）；k_a=(c2*_a)^{-1}, θ_a=(k_a λ_base)^{-1}（5）；g(t)∈{1; 1+A sin(2πt/T); 1+A(2t/H−1)}（6）；Λ(t)=∫_0^t g(s)ds（7）；T_k=Φ(T_k^raw), Φ=Λ^{-1}（8）；D_j^(0)=t_j+τ*W_j（9）；C_tot=HΣv_m（10）；∆C_tot=δ*C_tot（11）；C_b=H_b Σ v_m, ∆C_b+=C_b−[W_b/ρ*_b]_+（12）。
  - 经验度量层（从实现流 E 事后计算）：ρ_obs_global=W_tot/C_tot（13）；χ_obs_load=组利用率变异系数 sqrt((1/|G|)Σ_g(ρ_g−Meanρ)²)/Meanρ（14）；机器停机时长 T_down（15）；有效容量 C_b^eff（16）；瓶颈利用率 ρ_b^obs=W_b^win/C_b^eff（17）；c2_a,obs=(σ_∆t/µ_∆t)², c2_p,obs=(σ_p/µ_p)²（18）；交期紧度 τ_obs=(1/N_J)Σ_j (D_j−t_j)/W_j（19）；观测扰动 δ_obs=C_obs_down/C_tot（20-21）。
  - SSI 四分量：拥塞 C = ρ_nb·(1+(c2_a,obs+c2_p,obs)/2)/(1−ρ_nb)（22，ρ_nb=max_g ρ_g^obs，Kingman 重交通近似，直接编码"变异性×利用率"交互）；时间压力 P = 1/max(τ_obs,ε)（23，经验松弛的倒数）；结构复杂度 K = min(w_L·N_J^x/(M·MeanL), 1)（24，工序量相对机器容量）；扰动强度 S = min(δ_obs/S_max, 1)（25）。合成：ℓ(x)=log(1+x)，X̂=ℓ(X)/ℓ(X_max)（26）；**标量难度分 d = 100·(Ĉ+P̂+K̂+Ŝ)/4 ∈ [0,100]**（27）。
  - 校准层：度量集 L={ρ_global, c2_a, c2_p, τ, χ_load, δ, ε_bn}（28）；归一化误差 e_ℓ=|m_obs−m*|/(|m*|+ε)（29）；算子 T_s:E→E'（30）；Score(s)=Σφ(a_{s,ℓ},e_ℓ)（31）；非对称惩罚 φ（32，硬/软惩罚 λ_hard≫λ_soft，ε_tol≈0.05）；交期缩放迭代 α_{t+1}=α_t(1−η_τ sgn(τ_obs−τ*)e_τ)（34）；同构重采样（35）；瓶颈时长调整 dur(e)'≈dur(e)+∆C'_b/v_gb（36）；校准损失 ℓ_2=‖m_obs−m*‖₂。
  - 评测层：性能 = 相对每实例最优观测调度的归一化 makespan（Mean C_max%，含 p50/p90/p95 分布与 SE）；成本 = 总 token 消耗（百万计）；结果侧难度代理 Δ_gap = C_max(random)−C_max(best heuristic)；配对显著性检验（95% CI、FDR 校正 p）。

- **成本与预算处理**：
  是，token 与时间均被记录为一等指标。表3 明确并列报告 Tokens(10^6) 与 Mean C_max(%)：L1 Direct 3.752M / L1 CoT 4.016M / L1+Tool 12.614M / L2 CoT 6.883M / L2 Reflection 14.470M / L2 BestOfN 7.770M / L3 CoT 8.620M——"total token consumption to characterize the cost-performance trade-off" 是其显式评测目标。原文证据：工具增强带来约三倍 token 成本（12.6M vs 4.0M）但性能反而更差（2.0% vs 1.9%）；Reflection 14.47M 换来 1.7% vs L2 CoT 6.88M 的 0.7%。校准器侧同样记录 wall-clock runtime（表1）。**但没有硬预算上限/截断机制**：成本是事后计量而非事前约束；精化策略（greedy/reflection/best-of-n）被描述为"额外计算预算"的实现手段，评测中不设 token 封顶，也不报告每实例/每决策的细粒度成本分解。对成本受控评测体系而言，这篇提供的是"成本-性能联合报告"范式，而非"预算内运行"范式。

- **可复现处理**：
  项目主页 https://dsbx7.github.io/（正文脚注1；论文未在正文展开代码许可证/数据下载细节，应到主页核对）。可复现性设计相当扎实：(1) Gym 兼容环境（Gymnasium reset/step 接口）+ **快照仿真**：内核封装可变环境状态、只暴露不可变观测，每个决策 epoch 导出系统快照，确保 agent 决策不能破坏仿真时钟或状态一致性；trajectory-based engine 做可复现约束验证（先行约束、资源非重叠）。(2) 生成侧：配置四元组 + 每配置 5 个独立种子 + 显式随机分布族（Gamma/正态）+ 附录 K 给出全部关键公式推导（含式35 工作量守恒证明）。(3) 模型侧：跨模型比较（表5）用 matched 协议——相同 L1 Direct prompt 模板、two-shot 示例、temperature=0.0、top-p=1.0；模型版本明确锁定（Qwen3-4B/8B/14B/32B、Kimi-K2、Claude-4.5-Haiku、DeepSeek-V3.2、Gemini-2.5-FlashLite、Grok-4Fast、GPT-5-Mini）；开源权重用 vLLM 本地部署（Xeon 8468V + H100 80GB），闭源走 API。诊断引擎对每次执行轨迹做事后硬约束校验。

- **报告的 LLM 失败模式**（逐条，附原文证据）：
  1. **可观测性悖论（Observability Paradox）**：给智能体 oracle 级完整结构信息（L3：瓶颈分数、校准目标等设计层先验）反而降低策略性能，简洁统计摘要（L2）更优——L3 CoT 均值 1.66% vs L2 CoT 0.65%（表4），且 L2 的 p95 尾部也更小（2.01% vs 2.92%）；机理解读："current LLMs struggle to distill useful signals from high-dimensional noise"、"richer structural priors may create an information-to-action integration burden, especially in tail instances"。附录 J 机制消融（表 j-2，42 例配对）：仅加长度 V3/V1=0.998、加输入模型目标 0.999、加结构先验 1.001、改格式 V6/V2=1.002——单因素均值皆中性但 max ratio 膨胀（1.037/1.046），结论收窄为"富结构观测下的**尾部脆弱性**"而非 token 长度效应。
  2. **主动探测低效（信息整合瓶颈）**：L1+Tool（inspect-action / simulate-action 两个工具，多轮证据积累）2.0% 未能超过 L1 CoT 1.9%，token 却约三倍（12.614M vs 4.016M）——"the agent is unable to effectively synthesize the retrieved high-dimensional signals into superior dispatching actions"。
  3. **推理收益递减**：精化策略集体失效——Reflection 1.7%、Best-of-N 2.7% 均差于标准 L2 CoT 0.7%（图 j-1-Refinement）；"deeper reasoning chains do not compensate for the lack of aligned input features and may instead lead to stochastic drift away from optimal local heuristics"。
  4. **启发式平价/天花板（heuristic-ceiling）**：全部 LLM 聚集在窄性能带（Mean C_max ≈ 1.01%–1.93%），匹配强启发式但不突破天花板，"acting primarily as robust 'safe' approximators rather than transformative optimizers / robust heuristic approximators rather than superior optimizers"。配对检验：Qwen3-8B（最优 LLM，1.01%）与最强固定规则 LIFO+LIT（1.11%）统计不可区分（∆=−0.099pp，95%CI [−0.531,0.389]，FDR p=0.397）；Claude 能与弱规则 SPT+SPT 干净分离（−49.997pp，p<0.001）但不能持续超越最强规则；"The inability of top models like Claude to consistently outperform PDRs suggests limited combinatorial intuition"，作者据此呼吁研究重心"pivot from reactive dispatching to multi-step trajectory planning"。

- **可搬进 EvalBench 的零件**（3 个，含搬法）：
  1. **SSI 式"标量难度分 + 分位数分层"，在三档规模之外加一个受控难度维度**。搬法：为 EvalBench 的每类 OR 实例定义 3-4 个可从事后统计量计算的难度分量（如约束密度/可行域紧度→类比拥塞 C 的 (1+变异)/(1−利用率) 型公式、求解器资源压力→类比时间压力 P、实例结构复杂度→类比 K、扰动强度→类比 S），各自用 log 压缩 + 上界归一化后等权合成 0-100 分；用五分位（quintile）分层并在报告中呈现"难度-性能曲线"，检验 LLM 的增益是否只在低难度层出现。再用论文的**结果侧验证**套路：以"弱基线−强基线 gap"（我们可用 GLPK 贪心 vs Gurobi 最优）为外部难度代理，算 Spearman 相关与 top/bottom 分位差 + bootstrap CI，证明难度分有效。
  2. **SESC 的"保度量局部算子 + 贪心误差向量搜索"校准思想，消除我们实例库的随机雾**。搬法：不靠重新随机采样逼近目标分布，而是对种子实例做**保持关键总量守恒的同构变换**（如调变异系数时等比缩放保持总需求量，对应其式35 的 Σp 守恒；调紧度时 clip 保证可行域，对应式33），每步先算归一化度量误差向量，再按"改善大误差、不伤已收敛指标"的非对称效用选算子；把我们的实例池校准到预设的（利用率/约束紧度/扰动强度）目标格点上，使"难度"成为生成协议的显式设定而非随机种子副产品。
  3. **快照仿真 + 轨迹持久化 + token 记量的评测栈骨架，并补上它缺失的预算上限**。搬法：仿真/求解内核封装可变状态、只暴露不可变快照，每个决策点导出（防 LLM 干扰内核一致性）；Eval 模块把执行轨迹持久化为结构化记录，事后跑硬约束校验；每配置记录总 token 并与性能并列成"成本-性能"表（对齐其表3）。我们比它多做一步：设**事前 token 预算档位**（如 0.1M/1M/10M）并记录"每 1% 性能提升的 token 边际成本"，把它从描述性指标升级为受控实验变量——这正好回应它只做事后计量的空缺，也契合 EvalBench"成本受控"的定位。

- **局限**：
  (1) 覆盖面：只针对 DFJSP 单一问题域，虽以"OR+LLM 评测"立论，但结论向其他 OR 问题类外推未经验证。(2) LLM 实验规模受计算约束压缩到 70 实例子集，且跨模型比较统一用最简的 L1 Direct 协议，未在 L2/L3 层做跨模型配对。(3) 校准自身在高难度端失稳：图2 显示校准误差随难度分上升呈加速增长（cubic fit），最需要校准的高压实例恰恰最难校准；c2_p（加工时间变异）在 SESC 下失败率仍约 40%，χ_load 的种子间离散也偏大——即"把难度完全变成受控变量"这一目标在高压/高变异区未完全达成。(4) 对可观测性悖论的机理解释不闭合：机制消融六变体均未出现显著均值退化，作者只能收窄为"尾部脆弱性"解释，说明对"为什么结构先验有害"仍缺乏确定性归因。(5) 成本只做总量事后记录，无预算上限、无每决策细粒度分解，"成本受控"停留在报告层面。(6) 评测主指标单一（归一化 makespan 相对每实例最优），交期、能耗等被生成层定义的量未进入主结果表。(7) 复现材料主要指向项目主页，论文正文未明确代码/数据/提示词的发布形式与许可证，提示词模板细节（L1/L2/L3 具体编码）需另行获取。
